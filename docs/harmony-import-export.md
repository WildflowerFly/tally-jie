# Harmony 数据交换实现现状

状态：Implementing，非完整备份方案。入口：我的 → 导入 / 导出。

## 已公开的 v2 最小模板

CSV：UTF-8 BOM、CRLF、所有单元格双引号包裹、双引号翻倍，允许引号内换行。

```csv
"id","type","amount","accountId","categoryId","date","time","note"
"example-1","expense","12.30","账户实际ID","支出分类实际ID","2026-11-17","12:00","午餐"
```

- type 为 income/expense；amount 正十进制元，最多两位小数；日期 YYYY-MM-DD、时间 HH:mm。
- 账户/分类必须事先存在，本期不支持第三方列映射、名称自动建档、无ID导入。不同ID同额同时间视为不同记录，不能用业务相似度吞掉真实交易。
- 文本以 `= + - @ 制表符 回车 单引号` 起始时，导出额外前缀一个单引号；本模板导入对应去掉一个前缀。适用于本软件输出，不对任意外部CSV作自动识别承诺；避免表格软件把文本当公式。
- CSV 仅交换收支，不带附件、创建时间或预算等其他表。新导入历史创建时间为 null，不伪造。
- 目前不符合实施计划完整多表CSV模板，schemaVersion/名称/审计字段及其他实体表尚待补齐；以本文模板为当前实际支持范围。

JSON：独立标识 `format: TallyJie-Ledger`、`version: 2`、`data: LedgerData`；全量包含账户、分类、收支、转账、预算、附件引用元数据。JSON当前UI仅全量导出；CSV可选含边界日期区间。旧 diary/设置兼容归档、图片字节未打包，**不是完整迁移备份**。导入新附件引用缺本地资源时阻断，不生成悬空引用。旧v1和Flutter文件不走本接口。

## 安全与预览

- 文件导入上限8MiB，读取前 stat 检查；解析层文本长度亦限制。仍同步全量解析，分批/流式解析和行数独立限制待补，不能宣称大文件可用。
- 先完整校验再显示新增、重复数量；同ID同内容跳过，同ID异内容阻断，不允许静默覆盖。JSON比较当前使用序列化内容，键顺序不同可能保守判冲突。
- 校验关联、账本金额/普通账户负余额和预算重叠；预览取消不写入；预览修订号过期需重新选择校验；提交调用AppState现有单事务，失败保留现状。
- 单文件保存选择器取消有提示，完成写入并fsync才报成功；目标文件写入失败可能留下不完整导出文件，但不影响源账本。
- 尚缺逐行错误列表/映射预览、来源文件标识去重、附件/兼容归档可移植完整导出、多表导出及平台选择器/故障实测，Task13不能全勾选。
